🛒 Big Mart Sales Prediction

A Machine Learning project that predicts product sales for Big Mart outlets using historical sales data. The project involves comprehensive data preprocessing, exploratory data analysis (EDA), feature engineering, and regression modeling to estimate future sales accurately.

🚀 Features
Performed data cleaning and preprocessing
Handled missing values and categorical features
Conducted Exploratory Data Analysis (EDA)
Visualized feature distributions and correlations
Applied feature engineering techniques
Trained a regression model for sales prediction
Evaluated model performance using the R² Score

📈 Model Performance
Training R² Score: 0.636
Testing R² Score: 0.587

These scores indicate that the model captures a moderate proportion of the variance in sales and provides a reasonable baseline for prediction.
